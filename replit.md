# Dev Pulse Activity Dashboard

## Overview
An interactive developer activity dashboard built with React + Vite, featuring the AutoMem brand aesthetic. Displays weekly developer activity, repository stats, and pull requests with playful animations.

## Tech Stack
- **Framework**: React 18 + TypeScript
- **Build Tool**: Vite 7
- **Animation**: Framer Motion
- **Fonts**: JetBrains Mono, IBM Plex Mono

## Project Structure
```
devpulse/
├── src/
│   ├── components/
│   │   ├── Cards/         # StatCard, DayCard, RepoCard, PRCard
│   │   ├── Effects/       # SpringNumber, Particles
│   │   ├── Jack/          # Jack character SVG with animations
│   │   └── Layout/        # Header, HexSidebar
│   ├── hooks/             # Custom React hooks
│   ├── styles/            # Design tokens
│   ├── types/             # TypeScript types
│   └── data/              # Activity data JSON
├── public/                # Static assets
└── vite.config.ts         # Vite configuration
```

## Key Features
- Hex memory address sidebar navigation
- Animated stat cards with spring numbers
- Weekly activity cards with hover effects
- Jack character with multiple poses (wave, thumbsUp, sleeping, celebrate)
- Dark/Light theme toggle
- Responsive design for mobile

## Running Locally
```bash
cd devpulse
npm install
npm run dev
```

## Data Source
Activity data is loaded from `src/data/activity-data.json`, generated by the parent project's report generator.
