# Dev Pulse Activity Dashboard - Complete Interactive Redesign

## Vision
Transform this developer activity dashboard from a generic analytics page into a **playful, memorable experience** that feels like a living workspace. Think: if a retro terminal, a game UI, and a cozy indie dev's desk had a baby.

The page should have **personality** - it's not just showing data, it's celebrating the grind.

## Brand Identity (MUST MATCH)

This dashboard is part of the **AutoMem** ecosystem. Reference the brand:
- **Primary Gold**: `#D4A425` - use for accents, highlights, interactive elements
- **Background**: Dark with subtle texture - NOT generic beige
- **Typography**: Monospace for data/labels (JetBrains Mono, IBM Plex Mono), clean sans for headings
- **Aesthetic**: "Retro-futurist dev lab" - hex memory addresses, terminal vibes, but warm and inviting
- **Mascot**: There's a FloppyMascot (cute floppy disk character) in the ecosystem

## The Jack Character (CRITICAL)

Create an illustrated character that appears throughout the page:
- **Appearance**: Simple cartoon guy, messy hair, wearing a **yellow/gold sweater** (#D4A425 tones), round glasses, friendly expression
- **Style**: Chunky lines, slightly geometric, like a mix of Notion's illustrations and indie game art
- **NOT corporate clipart** - should feel hand-drawn and charming

### Character Placements & Animations:
1. **Peeking from corner**: Jack peeks up from bottom-right corner, waves when you hover. On mobile, he appears on scroll triggers.
2. **Behind activity cards**: When you hover on a day with high activity, Jack pops up behind the card giving a thumbs up
3. **Empty states**: When there's "No activity" Jack is sleeping with Z's floating up
4. **Pull request celebrations**: When PR is merged, tiny Jack does a little victory dance
5. **Easter egg**: Konami code triggers Jack doing a moonwalk across the screen

## Interactive Elements (GO WILD)

### Weekly Rhythm Section
- Cards should have subtle **depth and parallax** on mouse move
- Activity bars should **animate in** on scroll (stagger from left to right like days passing)
- Hover on a day: card lifts, shows detailed breakdown in a tooltip with smooth spring animation
- Click a day: expands inline with commit messages, files changed
- The "TODAY" badge should have a gentle **pulse glow** animation
- Add tiny **particle effects** when hovering over high-activity days (like code confetti)

### Project Breakdown
- Cards should feel like physical objects - subtle shadows, **slight rotation on hover** (like picking up a card)
- Repository entries should have a **typing animation** on first load
- The commit counts should **count up** when entering viewport
- Add a subtle **connection line** animation between related projects
- On hover, show a mini activity sparkline for that specific repo

### Pull Requests
- PR cards should slide in from the side with a staggered delay
- Merged PRs get a **green checkmark that draws itself**
- Add a subtle **breathing animation** to open PRs (they're alive, waiting)
- File counts should fan out like a deck of cards on hover

### Header Stats
- Numbers should have a **slot machine roll-up effect** on page load
- Add subtle **gradient shine** that sweeps across on hover
- The +/- line counts should have color-coded micro-animations

## Navigation & Polish

### Sidebar (Add One!)
- Add a left sidebar with hex memory addresses (like `0x0000`, `0x0010`, `0x0020`) as section markers
- Should fade in/out on scroll
- Current section highlighted in gold
- Collapses to icons on mobile

### Scroll Effects
- Implement **smooth scroll-linked animations** throughout
- Elements should have subtle parallax at different depths
- Add a **progress indicator** that fills as you scroll (make it look like a loading bar)

### Dark/Light Mode
- Default to dark mode matching AutoMem.ai
- Light mode should feel warm, not clinical (cream/paper textures, not stark white)
- Mode toggle should have Jack flipping a light switch

### Mobile Experience
- Jack character should peek from the bottom of the screen, swipe up to reveal full dashboard
- Cards should be swipeable horizontally for Weekly Rhythm
- Add **pull-to-refresh** that shows Jack waking up
- Haptic-ready interactions (design as if haptics exist)

## CSS Requirements

### Must-Have Techniques:
```css
/* Use CSS custom properties extensively */
--gold-primary: #D4A425;
--gold-secondary: #B8922A;

/* Use backdrop-filter for depth */

/* Container queries for component-level responsiveness */
@container (min-width: 400px) { ... }

/* Scroll-driven animations */
animation-timeline: view();

/* Layered gradients for depth */
background: 
  linear-gradient(...),
  radial-gradient(...),
  url('noise-texture.svg');
```

### Animation Library
- Use **Framer Motion** for React (or GSAP if vanilla)
- Implement proper **reduced-motion** fallbacks
- All animations should be 60fps smooth
- Use `will-change` strategically

## Sound Design (Optional but Encouraged)
- Subtle UI sounds on interactions (typing clicks, whooshes)
- Muted by default, toggle in corner
- Jack character has distinct sounds for different states

```
  utilities.css        # Helper classes
/hooks
  useScrollProgress.ts

  useInViewAnimation.ts
```

### Performance Requirements:
- Lazy load below-fold content
- Use Intersection Observer for scroll triggers
- Virtualize long lists
- Target < 100ms First Input Delay
- All images as SVG or modern formats (AVIF/WebP)

## Example Interactions

### Scenario: High Activity Day
1. User scrolls Weekly Rhythm into view
2. Cards animate in left-to-right with 50ms stagger
3. Today's card pulses gold
4. User hovers Saturday (344 lines added)
5. Card lifts with spring physics
6. Jack pops up behind card, thumbs up
7. Tooltip shows: "Big day! 344 lines across 5 repos"
8. Tiny gold particles float upward
9. User clicks - card expands showing commit list

### Scenario: Empty Day
1. Tuesday shows "No activity"
2. Card is slightly faded
3. Jack is sleeping in the corner with animated Z's
4. Hover text: "Everyone needs a break 😴"

## What NOT to Do
- ❌ Generic Material Design or Bootstrap styling
- ❌ Harsh shadows or gradients
- ❌ Boring linear animations
- ❌ Overly complex 3D (keep it 2.5D max)
- ❌ Auto-playing sounds
- ❌ Accessibility violations for the sake of aesthetics
- ❌ Heavy JS that blocks interaction
